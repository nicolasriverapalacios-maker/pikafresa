# Pikafresa

Sitio web de Pikafresa en Cancún: menú, personalización de productos, carrito, pedidos por WhatsApp y sucursales.

## Abrir el sitio

Abre `index.html` en el navegador o publica esta carpeta en un servidor de archivos estáticos. No requiere compilación.

## Archivos

- `index.html`: tienda y menú.
- `admin.html`: acceso al panel de administración.
- `css/`: estilos y animaciones.
- `js/`: conexión a Supabase, pedidos y administración.
- `img/`: fotografías e identidad visual.

Los productos, extras y la autenticación del administrador usan el proyecto de Supabase configurado en el sitio. La clave incluida es la clave pública de cliente; los permisos de acceso se gestionan en Supabase.
